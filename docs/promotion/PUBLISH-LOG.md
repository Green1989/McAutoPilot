## 经验教训（给下一次自动化发布）

1. 掘金 Markdown 编辑器是 CodeMirror，无障碍树里节点不稳定；可靠路径 = 系统剪贴板（PowerShell Set-Clipboard/SetImage）+ 视觉定位编辑区坐标 + 真实 Ctrl+V
2. 掘金发布面板（分类/标签）不在无障碍树里（正文把树撑爆被裁剪），靠截图+视觉子智能体定位坐标点击
3. 即刻 web 的图片按钮会触发 Chrome 原生文件对话框，该对话框不在 list_windows 里、也渲染不到截图上，但会让主窗口进入 disabled 模态态——卡死即来自这里；下次先剪贴板贴图（若支持）或提前研究对话框句柄
4. Chrome 窗口被最小化/移到副屏时截图与点击全部失效；ShowWindowAsync(9) 恢复，前台化需 min→restore→ALT→SetForegroundWindow 组合
5. 腾讯云 `write-new` 编辑器默认富文本模式，粘 Markdown 会以字面文本显示（审核驳回"部分内容格式有误"的根因）；顶部「切换 MD 编辑器」内容不迁移但自动存草稿，切完重贴全文即可
6. 腾讯云 MD 编辑器是左右分栏（左源码/右预览），中间分隔线约在编辑区中线——点击坐标避开；粘贴前务必确认焦点在编辑区（本次曾把正文误贴进标题框）
7. 已发布的腾讯云文章 curl 带浏览器 UA 可拿 200；互动数据在页面 `__INITIAL_STATE__` 的 articleInfo JSON（likeNum/favNum/commentNum）；掘金文章数据匿名抓不到，直接看作者登录态页面
